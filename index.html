⚙️ सेटिंग आणि डेटा सुरक्षा

Backup / Restore

फोनमध्ये Auto Save सुरू आहे; पण तो फक्त या फोनच्या Chrome मध्ये आहे. फोन बदलण्यापूर्वी किंवा Chrome चा Site Data पुसण्यापूर्वी JSON Backup Google Drive मध्ये सेव्ह करा.

Backup सेव्ह करण्याची पद्धत: JSON Backup तयार करा दाबा. Share उघडल्यास Google Drive निवडा; Share उघडले नाही तर फाइल Downloads मध्ये सेव्ह होईल. मग Google Drive → + → Upload → Downloads मधील VidyarthiMitra_Backup फाइल निवडा. Restore: Drive मधील JSON फाइल आधी फोनमध्ये डाउनलोड करा; नंतर JSON Backup Restore करा दाबून Downloads मधून ती फाइल निवडा. Restore केल्यास सध्याचा अॅप डेटा त्या Backup ने बदलला जाईल. सध्या Drive वर स्वयंचलित बॅकअप सुरू नाही; तो स्वतंत्रपणे जोडावा लागेल.

☁️ Firebase Cloud Backup

Google खात्याने सुरक्षितपणे जोडल्यावर विद्यार्थी, फी नोंदी आणि सेटिंग्ज Firebase Cloud Firestore मध्ये बॅकअप होतील. PIN क्लाउडमध्ये साठवला जाणार नाही. इंटरनेट नसताना फोनमधील Auto Save सुरू राहील; क्लाउड Sync साठी इंटरनेट आवश्यक आहे.

Cloud Backup सुरू करण्यासाठी Google खात्याने जोडा.

क्लाउडमधील आणि फोनमधील डेटा वेगळा असल्यास अॅप तुम्हाला Restore किंवा Upload निवडायला विचारेल. जुन्या JSON Backup ची सुविधा कायम राहील. Firebase ची मोफत वापर मर्यादा लागू आहे.
